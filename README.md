LEONIDA LEDGER — a GTA VI trophy guide & tracker for PlayStation 5. All 55 official trophies (1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden), each with an original guide in numbered steps — every step cites its sources. Seven sources read in full on 20 Nov 2026 (PowerPyx, OutputLag, KeenGamer, eGamers, the official list, GTA-Zone, GTA Vibes). Where the sources disagree (the 18-vs-15 meditations, four disputed secrets, the unconfirmed Bad Luck trophy), the guide shows both versions instead of picking one.

Features: a checklist with progress saved in the browser, grade counters, filters (story / missable / collectibles / activities / crime / side quests / hidden), a spoiler toggle that hides story trophies until earned, per-trophy counters for count trophies, a 7-stage roadmap to the platinum, a missables register, and a sources panel with per-source citation counts. Fully offline — no external files, fonts or images.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the entry output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
