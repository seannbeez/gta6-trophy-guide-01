LEONIDA CODEX — an offline guide and tracker for all 55 GTA VI trophies on PlayStation 5. Every trophy has its official name, description and grade, plus an original numbered-step guide with a source cited on every step. It tracks progress in the browser (localStorage), with filters by kind and grade, a spoiler setting that hides story trophies until earned, export and import of progress, a seven-stage roadmap to the platinum, and an honest register for the one possibly missable trophy, the two watches, the one unconfirmed trigger, the one single-source number and the five cases where the sources disagree. Seven sources were read in full on 20 Nov 2026; where they disagree, both versions are shown instead of one being picked.

## Run it

```sh
node serve.ts
# open http://localhost:8080

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/dossier.json — the entry the judge reads
```
